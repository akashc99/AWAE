Regex Cheatsheet Basics

A quick reference for common regular expression syntax.

Basic Characters & Anchors

.
Matches any single character (except newline characters, unless the 's' flag is used).
^
Matches the beginning of the string, or the beginning of a line if the multiline flag (m) is enabled.
$
Matches the end of the string, or the end of a line if the multiline flag (m) is enabled.
\b
Matches a word boundary (the position between a word character and a non-word character, or start/end of string).
\B
Matches a non-word boundary.
\
Escapes the next character, allowing you to match literal special characters like ., *, +, ?, (, ), {, }, [, ], ^, $, |, \. Example: \. matches a literal period.

Character Classes

\d
Matches any digit character (equivalent to [0-9]).
\D
Matches any non-digit character.
\w
Matches any word character (alphanumeric characters plus underscore: [a-zA-Z0-9_]).
\W
Matches any non-word character.
\s
Matches any whitespace character (spaces, tabs, line breaks, etc.).
\S
Matches any non-whitespace character.
[...]
Character Set: Matches any single character specified within the brackets. Example: [aeiou] matches any vowel.
[^...]
Negated Set: Matches any single character *not* specified within the brackets. Example: [^0-9] matches any non-digit.
[a-z]
Range: Matches any single character within the specified range. Example: [A-Za-z] matches any uppercase or lowercase letter.

Quantifiers (Repetition)

Quantifiers specify how many times the preceding element should be matched. By default, they are "greedy" (match as much as possible).

*
Matches the preceding element zero or more times. Example: a* matches "", "a", "aa", etc.
+
Matches the preceding element one or more times. Example: a+ matches "a", "aa", etc. (but not "").
?
Matches the preceding element zero or one time. Example: colou?r matches "color" and "colour".
{n}
Matches the preceding element exactly n times. Example: \d{3} matches exactly three digits.
{n,}
Matches the preceding element at least n times. Example: \d{2,} matches two or more digits.
{n,m}
Matches the preceding element at least n times but no more than m times. Example: \d{2,4} matches two, three, or four digits.
*?, +?, ??, {n,}?, {n,m}?
Lazy Quantifiers: Append ? to a quantifier to make it match as few times as possible (non-greedy). Example: <.*?> matches <b> in "<b>text</b>" instead of the whole string.

Grouping and Alternation

(...)
Capturing Group: Groups multiple tokens together and creates a capture group for extracting substrings or using backreferences. Example: (ha)+ matches "ha", "haha", etc.
(?:...)
Non-Capturing Group: Groups tokens together without creating a capture group. Useful for applying quantifiers to a sequence. Example: (?:GET|POST) matches "GET" or "POST" without capturing.
|
Alternation (OR): Matches either the expression before or the expression after the pipe. Example: cat|dog matches "cat" or "dog".
\1, \2, etc.
Backreference: Matches the text previously matched by the Nth capture group. Example: (['"]).*?\1 matches a string enclosed in matching single or double quotes.

Lookarounds (Zero-Width Assertions)

Lookarounds check for patterns before or after the current position without including them in the actual match.

(?=...)
Positive Lookahead: Asserts that the pattern inside the lookahead follows the current position. Example: \d+(?=px) matches digits only if they are followed by "px" (e.g., matches "10" in "10px").
(?!...)
Negative Lookahead: Asserts that the pattern inside the lookahead does *not* follow the current position. Example: q(?!u) matches "q" only if it's not followed by "u".
(?<=...)
Positive Lookbehind: Asserts that the pattern inside the lookbehind precedes the current position. *Note: JavaScript support is more recent and might have limitations.* Example: (?<=\$)\d+ matches digits only if they are preceded by "$" (e.g., matches "10" in "$10").
(?<!...)
Negative Lookbehind: Asserts that the pattern inside the lookbehind does *not* precede the current position. *Note: JavaScript support is more recent and might have limitations.* Example: (?<!#)\d+ matches digits only if they are not preceded by "#".

Flags / Modifiers

Flags modify the behavior of the entire regular expression. They are typically placed after the closing delimiter (e.g., /pattern/gmi).

g (Global)
Finds all matches in the string, rather than stopping after the first match.
i (Case-Insensitive)
Makes the matching ignore case. Example: /cat/i matches "cat", "Cat", "CAT", etc.
m (Multiline)
Treats the input string as multiple lines. Allows ^ and $ to match the start and end of each line, not just the entire string.
s (Dotall / Single Line)
Allows the dot . to match newline characters as well. *Note: Not universally supported in older JavaScript versions, but common in many regex engines.*
